# FP-Growth (frequent pattern)

FP-Growth (frequent pattern)
         ● Mitiga os problemas do apriori
            ○ multiple scans
            ○ lidar quando a quantidade de itens frequentes é grande
            ○ lidar quando o suporte mínimo é baixo
         ● FP-Tree: Baseado em árvore de prefixos para os padrões frequentes
            ○ nó raiz é rotulado como NULL
            ○ subárvores de itens prefixos filhos da raiz
            ○ tabela                de                 cabeçalho             de
               itens frequentes
