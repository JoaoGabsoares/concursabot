      difícil de fazer. Existem alguns motivos para isso acontecer: (a) a

      devemos deixar as métricas ﬁnalmente serem descartadas.

               Avaliação de Políticas de Dados

               A avaliação de ativos de dados é o processo de entender e
      calcular o valor econômico dos dados para uma organização. A chave
      para entender o valor de um item não fungível (como dados) é
      entender como ele é usado e o valor trazido por seu uso.
                O valor surge quando o benefício econômico do uso de
      dados supera os custos de aquisição e armazenamento, bem como o
      gerenciamento de riscos relacionados ao uso.
