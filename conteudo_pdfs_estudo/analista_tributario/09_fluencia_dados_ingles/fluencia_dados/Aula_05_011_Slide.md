       FUNDESJ/2019
       O Mapeamento objeto-relacional (ou ORM, do inglês: Object-relational mapping)
       consiste em uma técnica de desenvolvimento utilizada que reduzira impedância da
       programação orientada a objetos utilizando bancos de dados relacionais. As tabelas
       do banco de dados são representadas através de classes e os registros de cada tabela
       são representados como instâncias das classes correspondentes. Com esta técnica, o
       programador não precisa se preocupar com os comandos em linguagem SQL; ele irá
       usar uma interface de programação simples que faz todo o trabalho de persistência.

Prof. Raphael Lacerda

       PF/2018

       inúmeros emails, vídeos e textos advindos, em sua maioria, de

       informações, Marcos poderá inferir que se trata de um grande banco

       como cada arquivo possui um código único, poderá deduzir que esse
