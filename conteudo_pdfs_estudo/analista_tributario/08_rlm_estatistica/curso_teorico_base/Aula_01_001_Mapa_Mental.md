                                                            PROPOSIÇÕES SIMPLES

    PROPOSIÇÕES SIMPLES                                                                     NÃO PODE SER DIVIDIDA EM PROPOSIÇÕES MENORES.

A NEGAÇÃO DE UMA PROPOSIÇÃO SIMPLES P GERA UMA NOVA PROPOSIÇÃO SIMPLES ~P.


                                                                                                                   Q: "TAUBATÉ NÃO É A CAPITAL DO MATO GROSSO."
A MANEIRA MAIS COMUM DE SE NEGAR UMA SENTENÇA DECLARATIVA NEGATIVA CONSISTE EM REMOVER O
ELEMENTO "NÃO", TRANSFORMANDO-A EM UMA SENTENÇA DECLARATIVA AFIRMATIVA.
                                                                                                                   ~Q: "TAUBATÉ É A CAPITAL DO MATO GROSSO."


                                             NEM SEMPRE O USO DE UM ANTÔNIMO NEGA A PROPOSIÇÃO ORIGINAL. PARA A PROPOSIÇÃO "O GRÊMIO VENCEU O JOGO", É
    NEGAÇÃO USANDO ANTÔNIMOS                 ERRADO DIZER QUE A NEGAÇÃO SERIA "O GRÊMIO PERDEU O JOGO", PORQUE O JOGO PODERIA TER EMPATADO.

              PARA NEGAR UMA PROPOSIÇÃO SIMPLES FORMADA POR UMA ORAÇÃO PRINCIPAL E POR ORAÇÕES SUBORDINADAS, DEVEMOS NEGAR A ORAÇÃO PRINCIPAL.

P: "PEDRO RESPONDEU QUE ESTUDOU TODO O EDITAL."                                                             ~P: "PEDRO NÃO RESPONDEU QUE ESTUDOU TODO O EDITAL."

                                                      PROPOSIÇÕES COMPOSTAS

                                                     RESULTA DA COMBINAÇÃO DE DUAS OU MAIS PROPOSIÇÕES SIMPLES POR MEIO DO USO DE CONECTIVOS.
PROPOSIÇÕES COMPOSTAS


       CONJUNÇÃO (P ∧ Q)                                     É VERDADEIRA SOMENTE QUANDO AMBAS AS PARCELAS SÃO VERDADEIRAS.

   DISJUNÇÃO INCLUSIVA (P ∨ Q)                               É FALSA SOMENTE QUANDO AMBAS AS PARCELAS SÃO FALSAS.

   DISJUNÇÃO EXCLUSIVA (P ∨ Q)                               É FALSA SOMENTE QUANDO AMBAS AS PARCELAS TIVEREM O MESMO VALOR LÓGICO.

       CONDICIONAL (P → Q)                                   É FALSA SOMENTE QUANDO A PRIMEIRA PARCELA É VERDADEIRA E A SEGUNDA PARCELA É FALSA.

      BICONDICIONAL (P ↔ Q)                                  É VERDADEIRA SOMENTE QUANDO AMBAS AS PARCELAS TIVEREM O MESMO VALOR LÓGICO.


 A PALAVRA "NEM" CORRESPONDE A UMA CONJUNÇÃO "E" SEGUIDA DE UMA NEGAÇÃO "NÃO".

 A PALAVRA “SE” APONTA PARA A CONDIÇÃO SUFICIENTE: “SE P, ENTÃO Q”.

               TABELA-VERDADE; TAUTOLOGIA, CONTRADIÇÃO E CONTINGÊNCIA


                       𝑛 PROPOSIÇÕES SIMPLES DISTINTAS.                      O OPERADOR DE NEGAÇÃO "~" NÃO ALTERA O NÚMERO DE LINHAS.


   PASSO 1                   DETERMINAR O NÚMERO DE LINHAS DA TABELA-VERDADE.

   PASSO 2                   DESENHAR O ESQUEMA DA TABELA-VERDADE.

   PASSO 3                   ATRIBUIR V OU F ÀS PROPOSIÇÕES SIMPLES DE MANEIRA ALTERNADA.

   PASSO 4                   OBTER O VALOR DAS DEMAIS PROPOSIÇÕES.


TAUTOLOGIA                   É UMA PROPOSIÇÃO CUJO VALOR LÓGICO DA TABELA-VERDADE É SEMPRE VERDADEIRO.

CONTRADIÇÃO                  É UMA PROPOSIÇÃO CUJO VALOR LÓGICO DA TABELA-VERDADE É SEMPRE FALSO.


                             É UMA PROPOSIÇÃO CUJOS VALORES LÓGICOS PODEM SER TANTO V QUANTO F, DEPENDENDO DIRETAMENTE DOS
CONTINGÊNCIA
                             VALORES ATRIBUÍDOS ÀS PROPOSIÇÕES SIMPLES QUE A COMPÕEM.


                             P ∨ ~P É UMA TAUTOLOGIA

                             P ∧ ~P É UMA CONTRADIÇÃO
