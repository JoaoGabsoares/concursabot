O INTERVALO EXCLUSIVE É O NÚMERO DE DIAS QUE SE DEVE                                                 INTERVALO INCLUSIVE = (DIA FINAL − DIA INICIAL) + 1
SOMAR À DATA INICIAL PARA SE OBTER A DATA FINAL. PARA DIAS
