# CONCEITO             • Medida que descreve o valor mais frequente de um conjunto de

CONCEITO             • Medida que descreve o valor mais frequente de um conjunto de
                                          observações, ou seja, o valor de maior ocorrência.


           MODA                        • É útil para a determinação da medida de posição de variáveis
                                          qualitativas nominais, ou seja, variáveis não numéricas que não
                                          podem ser ordenadas.

  MODA PARA       • A moda é o elemento de maior frequência.
  DADOS NÃO       • A moda nem sempre existirá em um conjunto de valores.
  AGRUPADOS       • Com relação ao número de modas, o conjunto de pode ser classificado como:

                     o amodal: quando todos os elementos apresentam a mesma frequência.
                     o unimodal: quando a frequência de um elemento é maior que as frequências dos
                        demais elementos.

                     o bimodal: quando as frequências de dois elementos são iguais e maiores que as
                        frequências dos demais elementos.

  MODA PARA
DADOS AGRUPADOS
   POR VALOR
                  • A moda é o valor que apresenta a maior frequência absoluta.
