                                         GLOSSÁRIO DE TERMOS
      Faremos uma lista de termos que são relevantes ao entendimento do assunto desta aula. Caso
      tenha alguma dúvida durante a leitura, esta seção pode lhe ajudar a esclarecer.

      R: Uma linguagem de programação de código aberto e gratuito, frequentemente utilizada em
      análise estatística, mineração de dados e visualização de dados.

      Variável: Um nome dado a um valor em um programa, que pode ser armazenado e manipulado
      pelo programa.

      Tipo de Dado: Uma classificação atribuída a um valor ou objeto em um programa, que determina
      como ele pode ser manipulado.

      Coleção: Uma estrutura de dados que permite armazenar múltiplos valores em uma única
      variável.

      Operador: Um símbolo ou palavra-chave em um programa que realiza uma operação específica
      em um ou mais valores.

      Operador aritmético: Um operador que executa uma operação matemática, como adição,
      subtração, multiplicação ou divisão.

      Operador de comparação: Um operador que compara dois valores e retorna um valor booleano
      (verdadeiro ou falso) indicando se a comparação é verdadeira ou falsa.

      Operador de atribuição: Um operador que atribui um valor a uma variável.

      Operador lógico: Um operador que executa uma operação lógica em um ou mais valores
      booleanos, como AND, OR ou NOT.

      Operador de concatenação: Um operador que combina duas ou mais strings em uma única
      string.

      Operador de acesso: Um operador que permite acessar elementos individuais de uma coleção,
      como uma matriz ou uma lista.

      Estrutura de Seleção: Uma construção de programação que permite executar diferentes ações
      com base em uma condição.

      Estrutura de repetição: Uma construção de programação que permite executar um conjunto de
      instruções repetidamente com base em uma condição.

                                                   Introdução

      R é uma linguagem de programação e um ambiente de desenvolvimento integrado (IDE) usada
      principalmente para análise estatística e gráficos. Foi criada por Ross Ihaka e Robert Gentleman
      na Universidade de Auckland, na Nova Zelândia, em meados da década de 1990.

      Trata-se de uma linguagem de programação interpretada, o que significa que o código é
      executado linha por linha, em vez de ser compilado em um programa executável. Ela suporta
      muitas técnicas estatísticas, incluindo análise de regressão, teste de hipóteses, análise de séries
      temporais e modelagem preditiva.

      Uma das principais vantagens de R é a sua vasta coleção de pacotes, que fornecem funções para
      realizar tarefas específicas, desde a importação de dados até a visualização de gráficos
      complexos. Muitos desses pacotes são criados e mantidos pela comunidade de usuários de R e
      estão disponíveis gratuitamente no Repositório CRAN (Comprehensive R Archive Network).

      R é usado em muitos campos, incluindo ciências biológicas, economia, finanças, engenharia,
      psicologia e muito mais. Hoje em dia, é uma das linguagens de programação mais populares entre
      estatísticos e cientistas de dados.

                                                    Variáveis

      Em R, uma variável é um objeto que armazena um valor ou um conjunto de valores. É possível
      atribuir valores a uma variável usando o operador de atribuição "<-" ou "=" (embora a primeira
      forma seja mais comumente usada).

      Por exemplo, o código abaixo atribui o valor "Hello World!" à variável "x":


      x <- "Hello World!"



      Agora, sempre que "x" for chamado, o valor "Hello World!" será retornado.

      As variáveis em R têm algumas características importantes:

      Tipagem dinâmica: em R, as variáveis são de tipagem dinâmica, o que significa que o tipo de
      dados da variável é determinado automaticamente pelo valor atribuído a ela. Por exemplo, se
      uma variável é atribuída com um número inteiro, ela é do tipo "integer", se é atribuída com um
      número decimal, ela é do tipo "numeric".

      Case sensitive: as variáveis em R são case sensitive (diferença entre maiúsculas e minúsculas), o
      que significa que as variáveis "x" e "X" são diferentes.

      Nomes de variáveis: os nomes de variáveis em R devem começar com uma letra ou ponto (.),
      seguido de uma combinação de letras, números e pontos. Além disso, o nome da variável não
      deve ser uma palavra-chave em R. Exemplos válidos de nomes de variáveis incluem "idade",
      "nome.completo" e "quantidade_de_produtos".

      Escopo: o escopo de uma variável em R é definido pelo ambiente no qual a variável foi criada.
      Variáveis criadas dentro de uma função têm escopo local e não podem ser acessadas fora da
      função. Variáveis criadas fora de uma função têm escopo global e podem ser acessadas em todo
      o código.

                                                  Operadores

      Em R, um operador é um símbolo especial que representa uma operação ou uma transformação
      que é aplicada a um ou mais valores para produzir um novo resultado. Os operadores podem ser
      usados para realizar cálculos matemáticos, comparar valores, atribuir valores a variáveis e muito
      mais.


                                           Operadores Aritméticos


      São usados para realizar cálculos matemáticos em números. Os operadores aritméticos incluem
      adição (+), subtração (-), multiplicação (*), divisão (/), exponenciação (^) e operador de módulo
      (%%).

      Veja exemplos:

      # soma de dois números
      2 + 3

      # subtração de dois números
      10 - 5

      # multiplicação de dois números
      2 * 4

      # divisão de dois números
      10 / 2

      # exponenciação
      2^3

      # raiz quadrada
      sqrt(9)

      # valor absoluto
      abs(-5)




                                         Operadores de Comparação


      São usados para comparar dois valores e retornar um valor lógico (verdadeiro ou falso) com base
      na comparação. Os operadores de comparação incluem igualdade (==), desigualdade (!=), maior
      que (>), menor que (<), maior ou igual a (>=) e menor ou igual a (<=).

                                              Operadores Lógicos


      São usados para combinar valores lógicos e retornar um valor lógico. Os operadores lógicos
      incluem "e" lógico (&&), "ou" lógico (||) e negação lógica (!).

      Veja exemplos:

      a <- 5
      b <- 6
      a < b # retorna TRUE
      b < a # retorna FALSE

      a <- 5
      b <- 6
      b >= a    # retorna TRUE
      a >= b    # retorna FALSE
      a >= 5    # retorna TRUE

      a <- 5
      b <- 6
      a <= b    # retorna TRUE
      b <= a    # retorna FALSE
      a <= 5    # retorna TRUE

      a <- 5
      b <- 6
      c <- 7
      a < b & b < c      # retorna TRUE
      a < b & b > c      # retorna FALSE

      a <- 5
      b <- 6
      c <- 7
      a < b | b > c      # retorna TRUE
      a > b | b > c      # retorna FALSE

      a <- 5
      b <- 6
      !(a < b)     # retorna FALSE
      !(a > b)     # retorna TRUE

                                        Operadores de Concatenação


      São usados para unir strings, vetores e até data frames. O operador de concatenação é
      representado pelo sinal de adição (+) no caso de Strings.

      # Concatenando duas strings
      string1 <- "Olá"
      string2 <- "mundo!"
      concatenada <- string1 + string2
      print(concatenada)

      # Concatenando dois vetores
      vetor1 <- c(1, 2, 3)
      vetor2 <- c(4, 5, 6)
      concatenado <- c(vetor1, vetor2)
      print(concatenado)

      # Concatenando dois data frames
      df1 <- data.frame(a = c(1, 2, 3), b = c("x", "y", "z"))
      df2 <- data.frame(a = c(4, 5, 6), b = c("p", "q", "r"))
      concatenado <- rbind(df1, df2)
      print(concatenado)




                                            Operadores de Acesso


      São usados para acessar elementos em uma coleção de dados, como um vetor, matriz ou lista.
      Os operadores de acesso incluem colchetes simples ([]) e duplos ([[]]).

      # Acessando o primeiro elemento de um vetor
      vetor <- c(1, 2, 3)
      vetor[1] # retorna 1

                                                     Funções

      Uma função é um bloco de código que pode ser chamado repetidamente a partir de diferentes
      partes de um programa, permitindo que um programador crie um código modular, mais
      organizado e mais fácil de manter. Em R, as funções são criadas usando a palavra-chave
      "function".

      As funções em R podem ter argumentos de entrada, que são valores que podem ser passados
      para a função quando ela é chamada, e podem ter valores de retorno, que são valores que a
      função retorna quando ela é executada.

      As funções são importantes porque permitem que o código seja reutilizado em diferentes partes
      de um programa, economizando tempo e esforço de programação. Além disso, as funções
      também ajudam a manter o código organizado e legível, tornando-o mais fácil de entender e de
      depurar.

      Por exemplo, suponha que você precise calcular a média de uma lista de números em diferentes
      partes do seu programa. Em vez de escrever o mesmo código para calcular a média em cada
      ponto do seu programa, você pode criar uma função que calcula a média e, em seguida, chamá-
      la sempre que precisar dessa operação. O código seria mais organizado, mais fácil de manter e,
      se necessário, seria mais fácil modificar a função em um único local, em vez de fazer alterações
      em todo o código.

      Aqui está um exemplo de como criar e usar uma função simples em R para calcular a média de
      uma lista de números:


      # Define a função
      mean_list <- function(x) {
        mean(x)
      }

         x <- c (3, 5, 7)

         y <- c (1, 9, 11)

         print (x + y)

         Após a execução do programa, será obtido o seguinte resultado.

         [1] 36

         Comentários:

         Em R, a adição de vetores é feita elemento a elemento. O vetor x contém os elementos
         (3, 5, 7) e o vetor y contém os elementos (1, 9, 11). Quando você executa a operação x
         + y, o R adiciona o primeiro elemento de x ao primeiro elemento de y, o segundo
         elemento de x ao segundo elemento de y, e assim por diante. Portanto, o resultado
         seria um novo vetor com os elementos (3+1, 5+9, 7+11), ou seja, (4, 14, 18).

         A função print() exibirá então o vetor resultante, portanto, após a execução do
         programa, o resultado exibido será [1] 4 14 18, não 36.

         Portanto, a afirmação é incorreta.

      2. O que são variáveis em R?

      Resposta: Coleções em R são estruturas de dados que permitem armazenar múltiplos valores em

      5. Quais são os operadores em R?

      Resposta: Os operadores em R incluem operadores aritméticos, operadores de comparação,

      statements.

      Resposta: Estruturas de repetição em R são construções de programação que permitem executar
      um conjunto de instruções repetidamente com base em uma condição. Exemplos incluem for
      loops, while loops e repeat loops.

      12. Qual é a função da função median() em R?

      Resposta: A função median() é usada para calcular a mediana de um conjunto de valores
      numéricos em R. A mediana é uma medida estatística que representa o valor central de um
      conjunto de dados ordenados. Para calcular a mediana, os dados são organizados em ordem
      crescente ou decrescente, e o valor que se encontra exatamente no meio do conjunto é
      selecionado. Se houver um número ímpar de dados, a mediana é o valor do meio. Se houver um
      número par de dados, a mediana é a média dos dois valores do meio. A mediana é uma medida
      de tendência central robusta, menos sensível a valores extremos em comparação com a média
      aritmética. É frequentemente usada para resumir dados que não seguem uma distribuição
      simétrica.

      13. O que é uma distribuição em R?

      Resposta: Em R, uma distribuição refere-se a um conjunto de valores de uma variável aleatória.
      R oferece várias funções para trabalhar com diferentes distribuições de probabilidade, como a
      distribuição normal, distribuição binomial, entre outras.

      14. O que é um vetor em R?

      Resposta: Em R, um vetor é uma estrutura de dados unidimensional que armazena elementos do
      mesmo tipo. Ele pode conter números, caracteres, lógicos ou outros objetos em R. Os elementos
      de um vetor são acessados por meio de índices numéricos.

      15. O que é uma matriz em R?

      Resposta: Em R, uma matriz é uma estrutura de dados bidimensional que contém elementos do
      mesmo tipo. Ela é composta por linhas e colunas, e os elementos são organizados em uma grade
      retangular. As matrizes em R são úteis para armazenar dados tabulares, como uma planilha.

      16. O que é um array em R?

      Resposta: Em R, um array é uma estrutura de dados multidimensional que pode conter
      elementos do mesmo tipo. Ao contrário de matrizes que são restritas a duas dimensões, arrays
      em R podem ter mais de duas dimensões. Eles são úteis para armazenar dados em várias
      dimensões, como dados volumétricos ou dados de séries temporais multidimensionais.
