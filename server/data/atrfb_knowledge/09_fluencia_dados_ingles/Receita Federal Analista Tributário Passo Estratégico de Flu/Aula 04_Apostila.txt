     1. Qual das seguintes afirmações é verdadeira sobre o Big Data?

           A) Big Data se refere exclusivamente à quantidade de dados armazenados em tabelas relacionais.
           B) Big Data não está relacionado a soluções tecnológicas para lidar com grandes volumes de dados.
           C) Big Data envolve apenas dados estruturados, excluindo os dados não estruturados.
           D) Big Data é um termo utilizado para descrever grandes conjuntos de dados com variedade e
           velocidade de processamento.
           E) Big Data é um modelo de programação utilizado para análise de dados históricos.

           Comentários:

           A) Incorreta. Big Data não se refere exclusivamente à quantidade de dados armazenados em tabelas
           relacionais. O conceito de Big Data envolve não apenas a quantidade, mas também a variedade,
           velocidade e veracidade dos dados.
           B) Incorreta. Big Data está intimamente relacionado a soluções tecnológicas para lidar com grandes
           volumes de dados. É necessário o uso de tecnologias e abordagens específicas para coletar,
           armazenar, processar e analisar esses dados.
           C) Incorreta. Big Data não envolve apenas dados estruturados, mas também dados
           semiestruturados e não estruturados. A variedade de dados é uma das características essenciais do
           Big Data.
           D) Correta. Big Data é um termo utilizado para descrever grandes conjuntos de dados que possuem
           características como variedade, velocidade e volume de processamento. Essas características estão
           relacionadas à natureza dos dados e à necessidade de soluções específicas para lidar com eles.
           E) Incorreta. Big Data não é um modelo de programação específico. É um conceito amplo que
           abrange a gestão e análise de grandes volumes de dados, independentemente do modelo de
           programação utilizado.

           Gabarito: D

     7. Qual dos seguintes algoritmos de mineração de dados é baseado em aprendizado não
        supervisionado?

         A) K-means
         B) Naive Bayes
         C) Árvores de Decisão
         D) Regressão Logística
         E) SVM (Support Vector Machine)

         Comentários:

         A) Correta. O algoritmo K-means é um algoritmo de agrupamento (clustering) baseado em
         aprendizado não supervisionado. Ele agrupa os dados em clusters com base na similaridade entre
         os pontos de dados, sem a necessidade de rótulos prévios.
         B) Incorreta. O Naive Bayes é um algoritmo de classificação baseado em aprendizado
         supervisionado. Ele utiliza o teorema de Bayes para calcular a probabilidade de uma instância
         pertencer a uma determinada classe com base nas probabilidades condicionais dos atributos.
         C) Incorreta. As árvores de decisão são algoritmos de classificação e regressão, geralmente baseados
         em aprendizado supervisionado. Elas dividem os dados em diferentes caminhos de decisão com
         base nos atributos, para prever a classe ou o valor de saída.
         D) Incorreta. A regressão logística é um algoritmo de classificação binária baseado em aprendizado
         supervisionado. Ele utiliza a regressão para modelar a relação entre os atributos e a probabilidade
         de uma instância pertencer a uma classe específica.
         E) Incorreta. O SVM (Support Vector Machine) é um algoritmo de classificação e regressão baseado
         em aprendizado supervisionado. Ele mapeia os dados em um espaço dimensional superior para
         encontrar um hiperplano de separação que maximize a margem entre as classes.

         instância desconhecida com base nas classes dos vizinhos mais próximos, utilizando uma
         abordagem de votação ou média dos rótulos.
         D) Incorreta. O desempenho do KNN pode ser afetado por conjuntos de dados com alta
         dimensionalidade, pois o cálculo de distância se torna mais complexo e os vizinhos mais próximos
         podem não ser representativos o suficiente.
         E) Incorreta. O KNN não é um algoritmo de agrupamento (clustering).

     9. Qual das seguintes afirmações sobre a técnica de discretização está correta?

         A) A discretização baseada em frequência divide os valores em intervalos iguais.
         B) A discretização baseada em intervalos iguais mantém a ordem dos valores originais.
         C) A discretização baseada em limites arbitrários usa a média dos valores existentes para definir os
         intervalos.
         D) A discretização baseada em limites arbitrários não permite que os valores sejam agrupados em
         categorias.
         E) A discretização baseada em frequência é mais adequada para atributos numéricos contínuos.

         Comentários:

         A) Incorreta. A discretização baseada em frequência não divide os valores em intervalos iguais, mas
         sim com base na frequência de ocorrência de cada valor. Valores menos frequentes podem ser
         agrupados em um único intervalo, enquanto valores mais frequentes podem ser divididos em vários
         intervalos.
         B) Correta. A discretização baseada em intervalos iguais mantém a ordem dos valores originais.
         Nessa abordagem, os valores são divididos em intervalos de tamanho igual, preservando a ordem
         dos valores originais.
         C) Incorreta. A discretização baseada em limites arbitrários não utiliza a média dos valores existentes
         para definir os intervalos. Nessa técnica, os limites dos intervalos são definidos de forma arbitrária,
         sem levar em consideração as estatísticas dos valores existentes.
         D) Incorreta. A discretização baseada em limites arbitrários permite que os valores sejam agrupados
         em categorias. Nessa abordagem, os valores são mapeados em categorias específicas com base em
         limites definidos arbitrariamente.
