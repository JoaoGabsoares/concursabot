Solr
       O Solr é um servidor de pesquisa construído sobre o
  Apache Lucene,        uma biblioteca de recuperação de
  informações de software livre baseada em Java.
      Ele foi projetado para conduzir aplicações poderosas de
  recuperação de documentos, é baseado em padrões abertos
  e altamente extensível.
      As consultas Solr são URLs de solicitação HTTP simples e
  a resposta é um documento estruturado: principalmente
  JSON, mas também pode ser XML, CSV ou outros formatos, o
  que significa uma ampla variedade de clientes podendo usar
  o Solr como : outros aplicações da web a clientes de
  navegador, aplicações rich client e dispositivos móveis.

Solr
    O Solr permite que você crie um índice com muitos
 campos diferentes ou tipos de entradas.
    O esquema é o local onde você informa ao Solr como ele
 deve criar índices a partir de documentos de entrada e a
 unidade básica de informação do Solr é um documento, que é
 um conjunto de dados que descreve algo.
    Um documento sobre uma pessoa, por exemplo, pode
 conter o nome da pessoa, biografia, cor favorita e tamanho
 do sapato já um sobre um livro pode conter o título, autor,
 ano de publicação, número de páginas e assim por diante.
    No universo Solr, os documentos são compostos por
 campos, que são essas informações mais específicas.

Solr
       O tipo de campo especifica o tipo de dados armazenado
   e como ele deve ser interpretado pela ferramenta.
       Quando se adiciona um documento, o Solr pega as
   informações nos campos e as adiciona a um índice e quando
   uma consulta é feita, o Solr pode acessar rapidamente o
   índice e retornar os documentos correspondentes.
       A análise de campo informa ao Solr o que fazer com os
   dados recebidos ao criar um índice e pode realizar
   tratamento nos dados, e por fim, o Solr armazena detalhes
   sobre os tipos de campos e campos que se espera entender
   em um arquivo de esquema que é denominado managed-
   schema.xml ou schema.xml.

     A diferença é determinada por como você planeja
 gerenciar o esquema do Solr em sua instalação:
 programaticamente ou editando manualmente.
     Um fato importante sobre o esquema é que ele é um
 conceito Solr, mas os dados reais em seu índice são
 armazenados em Lucene que não tem o conceito de um
 esquema, ou seja, as alterações no arquivo de esquema não
 terão nenhum impacto nos dados já armazenados no índice.
     Na verdade, alterar o esquema sem reindexar seus dados
 pode causar sérios problemas com o índice, a ponto de a
 única solução ser reindexar totalmente seus dados.

Flink

    O Apache Flink é uma estrutura e um mecanismo de
 processamento distribuído para cálculos de estado em fluxos
 de dados ilimitados e limitados.
    Foi projetado para rodar em todos os ambientes de cluster
 comuns, realizar cálculos na velocidade da memória e em
 qualquer escala e os dados são produzidos como um fluxo de
 eventos.

Airflow

     O Apache Airflow é uma plataforma de código aberto para
 desenvolver, agendar e monitorar fluxos de trabalho
 orientados a lotes.
     Sua estrutura Python extensível permite criar workflows
 conectados a praticamente qualquer tecnologia e uma
 interface web ajuda a gerenciar seus estados.
     Ele pode ser implantado de várias maneiras, desde um
 único processo no laptop a uma configuração distribuída para
 suportar até mesmo os maiores fluxos de trabalho.


Informática
Profa: Emannuelle Gouveia
@Emannuelle Gouveia         https://t.me/KakashiAssinaturasBot
Airflow

    Os fluxos de trabalho como código servem a vários
 propósitos:

 ▪ Dinâmico: os pipelines do Airflow são configurados como
 código Python, permitindo a geração dinâmica de pipelines;
 ▪ Extensível: a estrutura do Airflow contém operadores para
 conectar-se a várias tecnologias. Todos os componentes são
 extensíveis para se ajustar facilmente ao seu ambiente;
 ▪ Flexível: a parametrização do fluxo de trabalho é integrada,
 aproveitando o mecanismo de modelagem Jinja.
